# Онлайн MiniCafe — запуск і розгортання

Онлайн всередині APK 3.40: docs/ANDROID-ONLINE-UA.md у корені репозиторію.
Міграція 0008 додає одноразовий app-login handoff; секрети Telegram не змінюються.

Адреса: https://minicafe.minicafe.workers.dev
Підтверджуване перенесення меню з онлайн-APK адміністратором: docs/MENU-TRANSFER-UA.md у корені репозиторію.
Міграція 0005 додає одноразові дозволи, прив’язані до сесії адміністратора.
Меню передається окремо від резервної копії; замовлення/статистика не замінюються.
Worker: minicafe; окрема D1: minicafe-db. Ідентифікатори ресурсів у wrangler.jsonc
не є паролями. Cloudflare-акаунт має збігатися з account_id цього файлу.

Версія 0.4: компактна сторінка доступів і заявки через @minicafe_loginbot.
Налаштування та робота заявок: docs/STAFF-REQUESTS-UA.md. Міграція 0006 додає
приватні профілі, заявки, захист від дублів та повернення в APK-перенесення
після OAuth. Webhook реєструється configure-bot.mjs register після deploy.
Bot Token і webhook secret — лише Workers Secrets/приватний локальний JSON.

Головна сторінка — публічне меню з короткими кодами. Міграція 0007 відкриває
гостьовий режим; адміністратор може закрити його на сторінці сервера.
Інструкція: docs/GUEST-CODES-UA.md. Коди не створюють оплачених замовлень.

Вхід персоналу: /admin → /auth/login (підказки) → /auth/start → Telegram OIDC
Authorization Code + PKCE у тій самій вкладці, без popup/iframe.
На сторінці Telegram доступний запасний вхід за номером телефону. Якщо сайт
відкрито у вбудованому браузері іншого застосунку, починати вхід заново у
Safari/Chrome; підтвердження завершувати в тому самому браузері, де cookie потоку.
Адміністратори: 600810855 та 1402380598, задаються ADMIN_TELEGRAM_IDS.
Інші акаунти допускаються лише після надання ролі адміністратором через
«Сервер → Доступи працівників». Ролі: service, cash, bar, delivery.
Доступ можна надати за Telegram ID або міжнародним номером (+380…). Для номера
запитується scope phone; сервер приймає тільки підписаний Telegram claim із
phone_number_verified=true. Перший підтверджений акаунт прив’язує номер до свого
ID; інший акаунт з тим самим номером доступ не успадковує. Зміна/відкликання
дозволу анулює його сесії. Явний запис дозволу за ID має пріоритет над номером,
навіть коли ID вимкнений. Номери зберігаються тільки у приватній D1 і доступні
адміністраторам. Це вхід через Telegram, окремої SMS-авторизації немає.
Без сесії закриті всі бізнес-API, історія, звіти, фото товарів та резервні копії.
PUBLIC_TEST_MODE видалено. Ключі локального APK не дають доступу до хмари.

У BotFather → Login Widget дозволити origin сайту та точний callback:
https://minicafe.minicafe.workers.dev/auth/callback . Client ID — у wrangler.jsonc.
Client Secret — лише Workers Secret TELEGRAM_CLIENT_SECRET. Для налаштування
створити приватний .env.telegram.local.json з TELEGRAM_CLIENT_ID,
TELEGRAM_CLIENT_SECRET, TELEGRAM_BOT_USERNAME; виконати node configure-telegram.mjs.
Цей файл, OAuth-конфіг .wrangler-auth і локальні бази не комітити/не архівувати.
Bot Token для цього способу входу не потрібний. Сесія діє до 7 діб; зміна ролі
чи відкликання доступу анулює сесії працівника. Cookie Secure/HttpOnly,
записи вимагають CSRF-токен і правильний Origin. Ролі перевіряються сервером.

## Локальна розробка без Cloudflare-акаунта

Потрібні Node (версія за вимогами зафіксованого Wrangler) та Python 3.10+.
З каталогу apps/online:

```sh
npm ci
python build.py
npm test
npx wrangler d1 migrations apply DB --local
node tests/seed-auth.mjs
npx wrangler dev --port 8791 --local
```

В іншому терміналі, доки dev-сервер запущений:

```sh
npm run test:api
npm run test:ui
```

API-тести навмисно відмовляються працювати з публічною адресою. Playwright для
UI береться зі спільного work/tooling; встановлення описане у START-HERE-UA.md.
Перевіряються Chrome/WebKit; це не перевірка фізичного iPhone чи Android.

## Публікація (власник акаунта)

Windows helper cf.ps1 ізолює авторизацію цього проєкту від інших акаунтів.
Не комітити .wrangler-auth, .wrangler, .dev.vars або .env. На іншому ПК потрібно
авторизуватися заново, переносити токени в Git не можна.

```powershell
.\cf.ps1 login --device --browser=false --scopes account:read user:read workers:write workers_scripts:write d1:write workers_routes:write
.\cf.ps1 whoami
python build.py
npm test
.\cf.ps1 d1 migrations apply DB --remote
.\cf.ps1 deploy
```

Підтвердити запит Wrangler у Cloudflare протягом строку дії коду. Для Linux/macOS
еквівалентно задати XDG_CONFIG_HOME в окремий приватний каталог і запускати
npx wrangler. Ключі не потрібні для локальних тестів.

Встановлений піддомен акаунта minicafe.workers.dev НЕ перейменовувати автоматично:
це впливає на адреси всіх Workers акаунта. Назва Worker minicafe дає кінцеву адресу
minicafe.minicafe.workers.dev. Після першої реєстрації піддомену TLS може ще не бути
доступний одразу; не вимикати перевірку сертифікатів і не підміняти це HTTP-входом.

## Дані та межі

- D1 окремо зберігає metadata/ревізію, товари, фото, замовлення, індекс позицій,
  сесії та витрати. Запис — атомарний batch із перевіркою очікуваної ревізії.
- Оновлюються тільки змінені рядки. Дубль request замовлення повертає той самий ID.
- Читання черги: усі незавершені, останні 30, а також потрібні для undo записи.
  Історія пагінується в SQL. Звіт завантажує лише обраний період.
- /api/state перевіряє одну ревізію й повертає 304 без завантаження даних, якщо
  стан не змінився. Опитування раз на 15 секунд, приховані вкладки не опитуються.
  Запис касира одразу оновлює його стан; інші клієнти бачать зміну наступним polling.
- Текстові/файлові статичні ресурси віддає Workers Assets; базові фото стиснуті.
  Власне JPEG-фото — до 450 КБ, запит до 700 КБ, резервна копія до 8 МБ.
- PDF зі шрифтом кирилиці створюється в браузері: CPU Free Worker не витрачається
  на шрифти й генерацію PDF. Шрифт/модулі завантажуються тільки при експорті.
- API не дозволяє cross-origin записи, перевіряє сесію, права, CSRF,
  числові поля, оплати та фото. Вхід має обмеження частоти спроб.
- Backup сумісний із форматом minicafe-android-1 та включає фото. При restore
  перевіряються дані, оплати, ID і сесії; черга undo скидається. Робоча Android-база
  автоматично не синхронізується. Відкритий cloud не має імпорту за довільним URL.
- Гостьове замовлення й перемикач його прийому — наступний етап.
  Тестові cookie з tests/seed-auth.mjs застосовуються тільки в локальній D1;
  не запускати цей seed проти віддаленої бази. Реальний Telegram-вхід перевіряє
  власник своїм акаунтом; локальні тести не підміняють перевірку Telegram у production.
- Квоти Workers/D1 спільні для акаунта. Гарантії безперервної роботи Free немає.

Статичні залежності: pdf-lib 1.17.1 (MIT), @pdf-lib/fontkit 1.1.1 (MIT),
DejaVu Sans (ліцензія включена). Ліцензії додаються до assets/vendor під час build.
Windows 3.36 заморожений; цей cloud-випуск не створює нових APK/EXE.
