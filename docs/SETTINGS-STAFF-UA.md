# Налаштування та працівники — 3.52 / online 0.19

Спільний UI: іконки Lucide (сімейство з каталогу 21st.dev), статичні SVG без React,
мережевих запитів чи залежностей. Повідомлення ліцензії — у settings-controls.js
та work/frontend/icons/LICENSE-Lucide.txt; скіл ui-ux-pro-max у репозиторій не встановлено.

Порядок налаштувань: Локації, Доступи працівників, гостьове меню, онлайн-оплата,
решта дій; вихід останній. Неактивні меню/оплата мають м’який червоний фон.
Назад з оформлення веде до налаштувань у браузері та нативному APK. Бічне меню
має іконки, без хрестика й рамки теми; у класичній палітрі рамки локацій нейтральні.
Перенесення меню називається «Синхронізувати» (лише онлайн-адміністратор APK).

У списках ролей автоматично є всі додаткові локації. Значення role@location
використовує тільки UI; сервер зберігає базову роль та окрему область доступу.
Старі глобальні ролі зберігають попередню поведінку. Нове призначення локації
обмежує стан черг, записи, видачу, повернення та карткові оплати цією локацією.
Службові назви/ціни історії та доступи до загального каталогу не змінюються.
Вхід через номер і Telegram ID має однакові перевірки області. Адміністратори
з ADMIN_TELEGRAM_IDS зберігають повний доступ. Зміна права атомарно оновлює
область і відкликає сесії; одне видалення прибирає право та відкликає доступ.

Натискання імені, ніка, номера чи ID відкриває візуальну назву. label зберігається
окремо, не змінює Telegram-профіль, ідентифікатор, номер, права або сесії.
Номер показується, якщо він був наданий; невідомий номер не вигадується.

Схема: migration 0015_staff_details.sql, таблиця staff_details(identifier,label,location),
ключ id:<telegram_id> або phone:<international_number>. Застосувати міграцію перед
deploy Worker: identityByHash використовує LEFT JOIN цієї таблиці. Дані меню й
історії не переносяться й не очищаються. Права залишаються окремими від cafe-backup.

Перевірки: повні Android checks.py (23 Java-набори, API, Chrome/WebKit), scoped
staff-locations.mjs проти локальної одноразової D1, settings-staff-ui.cjs для двох
рушіїв. Фізичний Android/iPhone не перевірявся. Windows 3.36 не змінюється.
