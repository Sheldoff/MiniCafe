# Чорно-біла тема та імена гостей — 3.56 / online 0.23

Налаштування → Оформлення → Чорно-біла. Світлий і темний вигляд перемикаються окремо; вибір зберігається на пристрої. Кавова тема залишається типовою для нових пристроїв. Відтінки сірого охоплюють CSS-токени, старі кольори, анімації, фокус, наведення, підсвічування товарів, графіки, меню й нативні екрани APK. Кольори локацій зберігаються в даних; у чорно-білій темі їхні елементи інтерфейсу нейтральні, після зміни теми кольори повертаються. Фото, брендова іконка та зразки вибору кольору не знебарвлюються.

Налаштування → Локації → потрібна каса → «Ім’я гостя обов’язкове». Типово вимкнено. Коли ввімкнено, сервер і форма вимагають непорожнє ім’я. При вимкненні порожнє поле показує підказку «Гість №1» — це не текст поля, тому при натисканні нічого стирати не потрібно. Сервер підставляє поточний номер при успішній оплаті. Введене ім’я, помилка оплати й повтор запиту не витрачають номер. Лічильник один для всього кафе, зберігається після перезапуску/завершення сесії та у резервній копії. Скасування замовлення не повертає вже використаний номер. На кількох пристроях підказка може бути попередньою до оновлення стану; фінальний унікальний номер завжди призначає сервер атомарно. Старі замовлення не перейменовуються.

«Меню й ціни» перейменовано на «Меню та ціни», список ущільнено у вебі й APK. Прибрано текст «У меню»; приховані товари зберігають позначку «Приховано». Фото, ціна, назва, пошук і редагування натисканням рядка збережені.

Статистика починається з перемикачів «Замовлення / Звіт / Онлайн». У вкладці Онлайн період приховано: дані лише поточної сесії; старий історичний вибір зберігається для інших вкладок. Автооновлення кожні 15 секунд збережене.

Зміни зберігаються в JSON-метаданих/локаціях: міграцій D1, нових секретів або зміни webhook немає. Windows заморожений. API й відновлення перевіряються лише на локальних одноразових базах; фізичні телефони не використовувалися.
