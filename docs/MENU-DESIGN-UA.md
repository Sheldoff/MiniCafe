# Меню й ціни — онлайн 0.21 / Android 3.54

Каталог оформлений у стилі статистики: спільна ширина робочої області, охайні відступи та кольори поточної теми. Угорі — назва сторінки й основна кнопка «Новий товар», далі — підписаний пошук із кількістю результатів. На широкому екрані картки утворюють дві колонки, на вузькому — одну. Картка показує фото, назву, категорію, окрему ціну та стан «У меню / Приховано». Видалення відокремлене від даних товару, має власну доступну назву й зберігає підтвердження.

Натискання картки, Enter або пробіл відкриває редактор. Список прихований, доки редактор відкритий. Поля згруповані в «Основні дані», «Ціна й наявність» та «Фото й видимість». На ноутбуці дані й фото розташовані поруч, на вузькому екрані — послідовно. Усі поля мають пов’язані підписи. Фото показується більшим і зберігається разом із товаром основною кнопкою «Зберегти»; дубль кнопки збереження біля фото прибраний. Кнопки збереження й закриття залишаються в одному рядку. Чернетка та системна кнопка «Назад» працюють як раніше.

Новий CSS: `work/frontend/css/menu-prices.css`, підключений через спільний manifest для онлайн та APK. Суми, API, права, дані меню й залишки не змінювалися; нових міграцій чи секретів немає. Windows заморожений.

Цільовий сценарій `work/tests/ui/menu-prices-design.cjs` перевіряє Chrome/WebKit, ширини 320/390/768/1440 px, кавову/класичну світлу/темну палітри, контраст, відсутність переповнення, розміри кнопок, пошук і лічильник, клавіатуру, ізоляцію видалення та збереження чернетки без запису в каталог. Усі API-перевірки виконуються на локальних одноразових даних. Повний реліз потребує `work/scripts/checks.py` без пропусків, оригінального підпису APK та окремого Cloudflare deploy.
