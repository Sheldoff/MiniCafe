# Гостьове меню й коди — онлайн 0.5

1. Відвідувач відкриває головну сторінку сайту. Напис «МініКафе» веде до входу
   працівників через Telegram; окремої кнопки входу немає.
   Над списком виділено обов’язкове поле «Ім’я та прізвище»: потрібні обидві
   частини, до 100 символів. Ім’я передається касиру при завантаженні коду.
2. «Вибрати напій» відкриває список усіх активних позицій з обробником `bar`.
   Кнопки −/+ змінюють кількість, «Підтвердити» переносить вибір у замовлення.
   Натискання вибраних напоїв повторно відкриває редактор. Закриття без
   підтвердження залишає попередній вибір.
3. Їжа (`instant`) показується окремими рядками з ціною та кнопками −/+.
   Натискання рядка відкриває редагування цієї страви.
4. «Оформити замовлення» видає шестизначний код на 30 хвилин. Код потрібно
   назвати касиру. Повторне відкриття незміненого вибору показує той самий код
   у поточній вкладці до завершення його терміну.
   «Показати код» повторно відкриває його; «Нове замовлення» у вікні коду
   очищає вибір, щоб можна було оформити наступне замовлення, зокрема таке саме.
5. Касир натискає «Код» праворуч від категорій, вводить цифри й завантажує
   склад у звичайне замовлення. Якщо кошик непорожній, потрібне підтвердження
   його заміни. Ім’я, кількість, коментарі, ціни та оплату можна перевірити й
   змінити звичайним способом. Оплата і відправлення — через звичайну касу.

Код — це чернетка, а не бронювання чи платіж. Він не змінює залишки,
виручку, сесію й черги видачі. Наявність і актуальні ціни перевіряються сервером
при створенні коду, завантаженні на касу та остаточному формуванні замовлення.
Після успішного збереження оплаченого/подарункового замовлення код використаний;
повтор мережевого запиту того самого замовлення не створює дубль.

## Керування і зберігання

Адміністратор → Сервер → «Гостьове меню: відкрите/закрите». Зміна вимагає
підтвердження. Закриття приховує меню та одразу блокує нові коди; уже видані
коди можна прийняти на касі до закінчення терміну. Публічний список може
кешуватися браузером до 15 секунд; створення коду перевіряє налаштування наживо.

Міграція `0007_guest_codes.sql` використовує наявну `public_settings` і додає
тимчасові `guest_codes`. Робочі меню/історія не замінюються. Код зберігається
лише як SHA-256, дані чернетки — ім’я гостя, ID та кількість. Ім’я не повертається
публічним списком або API створення коду; його читає лише авторизована каса.
Коди автоматично очищаються
за індексом терміну придатності при створенні наступних; активний набір
обмежений 5000 записами. Коди й налаштування публікації не входять у переносну
резервну копію APK/веб; це окремі онлайн-дані.

Публічні API: тільки список видимих товарів і створення коду, без історії,
імен гостей, фінансів, прав чи доступу до керування. Введення коду доступне
лише admin/cash/service із Telegram-сесією, CSRF та обмеженням частоти.
З інших сайтів запис заборонений. Ціна з клієнта не приймається. Використання
коду і замовлення записуються в одній атомарній D1-транзакції.

## Перевірки

Лише локальна одноразова D1. Для іншого вільного порту задайте
`CAFE_CLOUD_TEST_URL=http://127.0.0.1:8897` і запустіть Wrangler на цьому порті.
`npm test`, `npm run test:api`, `node tests/guest-ui.cjs`,
`node tests/viewport-ui.cjs`, `node tests/design.cjs`.

Каркас адміністративної сторінки обмежений висотою viewport; довгі розділи
прокручуються всередині. Бічне меню та затемнення мають явну висоту `100dvh`.
Десктопні браузери не відтворюють системну навігаційну область фізичного Android.
