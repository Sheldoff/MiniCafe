# Гостьове меню й коди — Android 3.40 / онлайн 0.8

Онлайн: відвідувач відкриває головну сторінку сайту. Працівники входять окремим
посиланням /admin; напис «МініКафе» у гостьовому меню не відкриває авторизацію.

Локально: власник запускає сервер телефона та відкриває «Гостьове меню» на
екрані сервера. Тут можна відкрити/закрити приймання та скопіювати посилання
для Wi-Fi або збереженої адреси Termux. Гостьова адреса — /guest без ключа
персоналу. Спочатку гостьове меню локального сервера закрите. Телефон-сервер
повинен працювати; в одній мережі інтернет для цього не потрібний.

1. Відвідувач заповнює обов’язкові ім’я та прізвище (до 100 символів).
2. «Вибрати напій» відкриває напої (обробник bar), нижче — їжа (instant).
   Кнопки −/+ змінюють кількість; вибрані рядки можна відкрити для редагування.
3. «Оформити замовлення» видає код із трьох цифр (100–999) на 30 хвилин.
   Повторний перегляд незміненого вибору в цій вкладці показує той самий код.
   «Нове замовлення» очищає вибір.
4. На касі кнопка «Код» праворуч від категорій показує неоплачені коди та імена.
   Натисніть рядок або введіть код. Завантаження не вилучає його зі списку.
5. Касир перевіряє склад, ім’я та оплату і відправляє звичайне замовлення.
   Тільки успішна оплата атомарно забирає код. Невдала оплата його зберігає;
   повторення того самого платіжного запиту не створює дубліката.

Код не резервує залишок, не створює сесію й не змінює виручку чи черги.
Наявність і ціна перевіряються сервером; клієнтська ціна не приймається.
Використані коди не перевидаються до закінчення 30 хвилин. Одночасний простір —
900 кодів; прострочені очищаються при створенні наступного. Закриття меню
забороняє нові коди, але вже створені можна оплатити до закінчення строку.

Публічні API містять лише видимий каталог і створення коду. Історія, чужі імена,
фінанси, фото персоналу, доступи й керування залишаються захищеними. Перелік і
завантаження кодів доступні тільки admin/cash/service. Онлайн це Telegram-сесія
і CSRF, локально — відповідний ключ персоналу. З інших сайтів запис заборонений.
Локальні коди зберігаються в атомарному файлі даних телефона та переживають
перезапуск; у хмарі — в окремій D1. Це незалежні списки. Перенесення меню не
переносить коди. У переносній копії телефона вони можуть зберігатись до expiry;
онлайн-відновлення їх не імпортує. Не використовуйте коди старої копії як нові.

Перевірки: GuestOrdersTest, GuestApiTest і спільний tests/guest-ui.cjs для
Chrome/WebKit проти одноразового локального сервера. Фізичні пристрої не
підміняються цими перевірками.
