## Як отримати код на телефоні та ввійти на ноутбуці

1. На ноутбуці відкрийте https://minicafe.minicafe.workers.dev/auth/login
   і натисніть **Отримати код у боті на телефоні**.
2. На телефоні відкрийте @minicafe_loginbot і надішліть **/login**.
   Можна використати https://t.me/minicafe_loginbot?start=login і Start.
3. Введіть отриманий код МініКафе на ноутбуці та натисніть **Увійти**.

Telegram на ноутбуці не потрібний. Це окремий код **МініКафе**, не пароль,
не SMS і не код авторизації самого Telegram. Код із 10 цифр діє 5 хвилин,
одноразовий; новий скасовує попередній. Нікому його не передавайте.
Він доступний лише акаунтам з уже наданими правами. Бот не надає ролі сам.
Неприв’язаний дозвіл за номером спершу потребує звичайного перевіреного OIDC-входу.

Раніше існував тільки OIDC, прив’язаний state/PKCE/cookie до початкового браузера;
бот обробляв заявки, але не видавав код для іншого пристрою. Цю перевірку OIDC
збережено, додано окремий серверний шлях /auth/code через приватний webhook.
Android browser→APK proof/підтвердження також зберігається з новим способом входу.

## Розгортання й перевірки

Міграція **0013_bot_login.sql** додає окрему таблицю хешів кодів і строку дії.
Дані меню/замовлень не змінюються. Нових секретів немає. Не змінювати webhook
і не перевипускати Bot Token: використовуються наявні Workers Secrets.

Код видається лише через перевірений приватний Telegram update; update_id
відсіює повтори. На сервері: обмеження спроб, Origin/CSRF, Secure/HttpOnly cookie,
атомарне споживання коду й повторна перевірка актуальних ролей перед сесією.
У БД немає відкритих кодів, код не включається в URL чи журнали.
Заявки на доступ працюють окремо як раніше.

Локальні unit тести: npm test. API — тільки локальна одноразова D1.
UI теми: work/tests/ui/coffee.cjs в Chrome/WebKit для Android і онлайн.
Вхід між двома браузерними контекстами: npm run test:bot-login;
потрібен локальний HTTPS, бо WebKit не приймає Secure cookie через HTTP:

```powershell
node node_modules/wrangler/bin/wrangler.js dev --local --port 8791 --local-protocol https --var TELEGRAM_BOT_TOKEN:local-test --var TELEGRAM_WEBHOOK_SECRET:local-test-secret
# В іншому терміналі, apps/online:
npm run test:bot-login
```

Тести використовують підроблений webhook тільки в локальній D1. Реальний вхід
зі своїм Telegram на фізичному телефоні перевіряє власник. Автотести його не
підміняють. Windows не змінюється та не збирається.

Telegram API: https://core.telegram.org/bots/api та
https://core.telegram.org/bots/features#deep-linking .
