# Інтерактивна статистика — 3.58 / online 0.25

Видача має іконку пончика. Розділювач у локаціях — після трьох стандартних точок. У редакторі створених локацій є видалення; основні точки захищені сервером.

Статистика: прибрані видимі підписи періоду/назви, олівець біля завершення відкриває діалог назви. PDF — під звітом. Онлайн не містить старих KPI чи таблиці періодів.

Лінійка показує останню годину з хвилинним кроком, окремий рядок на касу. Одночасні чеки об’єднані в позначку; натискання відкриває всі позиції й номери. Прокручування та відкриті позначки зберігаються при автооновленні (15 секунд).

Порівняння: каси, видачі/бариста, напої або всі позиції; показники — кількість замовлень, порції, сума, середньозважена ціна порції. Фільтр каси включає створені додаткові каси. Напої й оплати реагують на цей фільтр. Графік у часі підтримує всі показники й показує нульові хвилини. Оплати порівнюються за сумою або кількістю (змішаний чек має обидва способи). Усі каси для оплат — підсумок цілої сесії; детальні порівняння та вибрана каса використовують до 500 останніх чеків, що підписано в інтерфейсі. Скасовані позиції виключені з деталізації; спільне замовлення на кількох видачах рахується в кожній, їхні числа не слід підсумовувати як унікальні продажі.

Проєкції цін, маршрутів і оплат лише для адміністративного stats API. Міграцій, нових секретів і змін webhook немає. Windows заморожений. Тести лише на локальних одноразових базах; фізичні телефони не використовувалися.
